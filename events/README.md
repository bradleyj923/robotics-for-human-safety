# Events and ways to keep exploring

## Upcoming: Physics AI DevDay 2026
**Tuesday, November 17, 2026 · 11 a.m.–4:30 p.m. U.S. Central**  
Organizer's time: **9 a.m.–2:30 p.m. Pacific**  
**Virtual · Registration and on-demand access:** [Luminary event page](https://luminary.ai/devday/)

Luminary's program brings together physics, AI and engineering through a keynote, technical sessions and a hands-on workshop. Listed speakers include CEO Pete Schlampp, CTO Juan Alonso, CPO Suds Menon and NVIDIA's John Linford. The agenda covers data generation, model architectures, model trust, improvement and an agentic Physics AI platform.

**Why it fits this collection:** Robots must work in the physical world. Better models of that world can inform engineering and testing. This is a connection to explore, not a claim that every session is about robotics.

**For students:** Start with the keynote. Pick one technical session that stretches you. Write down three unfamiliar terms and one question you would ask the speaker. Registrants can access sessions on demand afterward; the hands-on workshop has limited seats and a separate request checkbox.

*Details checked November 13, 2026. Check the organizer's page for changes. After the event, this entry serves as an archive and recording-access pointer rather than an upcoming-event announcement.*
